🧭 General raíz de la API

GET / Público

Información general: mensaje de bienvenida, versión y mapa de apartados.

Ejemplo curl http://localhost:8000/
GET /api/salud Público

Comprueba que la API está viva. Devuelve {"estado": "ok"}.

Ejemplo curl http://localhost:8000/api/salud

🔐 Autenticación /api/auth

POST /api/auth/registro Público

Crea una cuenta y devuelve el par de tokens (inicia sesión al instante). HTTP 201.

Cuerpo y respuesta

Cuerpo JSON

{ "nombre": "Maic", // 2–50 caracteres "email": "maic@ejemplo.com", // único "password": "secreto123" // 6–72 caracteres }

Respuesta (201)

{ "access_token": "...", "refresh_token": "...", "token_type": "bearer", "expira_en_segundos": 28800, "refresh_expira_en_segundos": 604800, "usuario": { ... } }
POST /api/auth/login Público

Inicia sesión con email y contraseña y devuelve el par de tokens.

Cuerpo y respuesta

Cuerpo JSON

{ "email": "maic@ejemplo.com", "password": "secreto123" }

Errores

401 · Email o contraseña incorrectos 403 · La cuenta está desactivada
POST /api/auth/refresh Público

Renueva la sesión con el refresh token, sin contraseña. El refresh anterior queda anulado (rotación).

Cuerpo

Cuerpo JSON

{ "refresh_token": "eyJhbGciOiJIUzI1NiIs..." }
POST /api/auth/cambiar-password Token

Cambia mi propia contraseña (cualquier rol). Exige la actual y anula todas las demás sesiones. Devuelve un par de tokens nuevo.

Cuerpo

Cuerpo JSON

{ "password_actual": "secreto123", "password_nueva": "clave-nueva-123", // distinta de la actual "confirmar": "clave-nueva-123" // debe coincidir }
GET /api/auth/yo Token

Datos de la cuenta autenticada (id, nombre, email, rol, activo, fecha de registro).

Ejemplo curl http://localhost:8000/api/auth/yo \ -H "Authorization: Bearer TU_ACCESS_TOKEN"

🕹️ Videojuegos /api/videojuegos

GET /api/videojuegos Token

Lista el catálogo con filtros, búsqueda, ordenación y paginación.

Parámetros de consulta
ParámetroTipoDescripción
qstringBusca por título o descripción (1–100 caracteres).
generostringID o nombre del género (ej. 3 o RPG).
plataformastringID o nombre de la plataforma.
desarrolladorastringID o nombre de la desarrolladora.
anio_desdeintAño mínimo de lanzamiento (1970–2035).
anio_hastaintAño máximo de lanzamiento (1970–2035).
ordenstringtitulo-asc (defecto) | titulo-desc | anio-asc | anio-desc | recientes.
paginaintPágina (mínimo 1, defecto 1).
por_paginaintResultados por página (1–100, defecto 20).

Ejemplo

curl "http://localhost:8000/api/videojuegos?genero=RPG&orden=anio-desc&por_pagina=5" \ -H "Authorization: Bearer TU_ACCESS_TOKEN"
GET /api/videojuegos/{videojuego_id} Token

Ficha completa de un juego: carátula, descripción, desarrolladora, plataformas y géneros.

Ejemplo curl http://localhost:8000/api/videojuegos/1 \ -H "Authorization: Bearer TU_ACCESS_TOKEN"
POST /api/videojuegos Gestor

Crea un videojuego en el catálogo. HTTP 201.

Cuerpo

Cuerpo JSON

{ "titulo": "Elden Ring", "descripcion": "Un vasto mundo de fantasía...", "caratula_url": "https://placehold.co/600x800?text=Elden+Ring", "anio_lanzamiento": 2022, // 1970–2035 "clasificacion": "PEGI 16", // opcional "puntuacion": 9.5, // opcional, 0–10 "desarrolladora_id": 1, // opcional (null = sin asignar) "plataformas_ids": [1, 2], // IDs de plataformas "generos_ids": [1, 3] // IDs de géneros }
PUT /api/videojuegos/{videojuego_id} Gestor

Actualiza un videojuego. Es parcial: solo se modifican los campos enviados.

Cuerpo

Cuerpo JSON (ejemplo parcial)

{ "puntuacion": 9.7, "generos_ids": [1, 3, 5] }
DELETE /api/videojuegos/{videojuego_id} Gestor

Elimina un videojuego del catálogo (arrastra los ejemplares de las colecciones).

Respuesta { "mensaje": "Videojuego eliminado correctamente", "id": 1 }

💾 Plataformas /api/plataformas

GET /api/plataformas Token

Lista todas las plataformas ordenadas por nombre (sin paginar).

GET /api/plataformas/{plataforma_id} Token

Obtiene una plataforma por su ID.

POST /api/plataformas Gestor

Crea una plataforma. HTTP 201. Devuelve 409 si ya existe otra con el mismo nombre.

Cuerpo

Cuerpo JSON

{ "nombre": "Nintendo Switch", // 2–100 caracteres, obligatorio "fabricante": "Nintendo", // opcional "anio_lanzamiento": 2017 // opcional, 1970–2035 }
PUT /api/plataformas/{plataforma_id} Gestor

Actualiza una plataforma (parcial: solo los campos enviados).

DELETE /api/plataformas/{plataforma_id} Gestor

Elimina una plataforma. Devuelve 409 si está en uso por videojuegos o ejemplares.

📚 Colección /api/colecciones

GET /api/colecciones Token

Lista tu colección (cada usuario solo ve la suya) con filtros y paginación.

Parámetros de consulta
ParámetroTipoDescripción
qstringBusca por título o descripción del videojuego.
estadostringnuevo | como nuevo | bueno | aceptable | malo | digital.
favoritobooltrue = solo favoritos; false = solo no favoritos.
plataformastringID o nombre de la plataforma del ejemplar.
valoracion_minintValoración mínima (1–10).
ordenstringfecha-desc (defecto) | fecha-asc | valoracion-desc | precio-desc | titulo-asc.
paginaintPágina (mínimo 1, defecto 1).
por_paginaintResultados por página (1–100, defecto 20).

Ejemplo

curl "http://localhost:8000/api/colecciones?favorito=true&valoracion_min=8" \ -H "Authorization: Bearer TU_ACCESS_TOKEN"
GET /api/colecciones/{item_id} Token

Obtiene un ejemplar de tu colección (404 si no existe o es de otro usuario).

POST /api/colecciones Token

Añade un videojuego del catálogo a tu colección. HTTP 201. Devuelve 409 si ya lo tienes en esa plataforma.

Cuerpo

Cuerpo JSON

{ "videojuego_id": 1, // obligatorio (del catálogo) "plataforma_id": 2, // opcional (null = digital/cualquiera) "estado": "bueno", // defecto: "bueno" "fecha_compra": "2024-05-17", // opcional (AAAA-MM-DD) "precio_compra": 59.99, // opcional, mínimo 0 "valoracion": 9, // opcional, 1–10 "favorito": true, // defecto: false "notas": "Edición física" // opcional, máx. 2000 }
PUT /api/colecciones/{item_id} Token

Actualiza un ejemplar (parcial). Puedes cambiar su plataforma, estado, precio, valoración, notas…

Cuerpo

Cuerpo JSON (ejemplo parcial)

{ "estado": "como nuevo", "valoracion": 10 }
PATCH /api/colecciones/{item_id}/favorito Token

Marca o desmarca un ejemplar como favorito (⭐).

Cuerpo

Cuerpo JSON

{ "favorito": true }
DELETE /api/colecciones/{item_id} Token

Elimina un ejemplar de tu colección.

Respuesta { "mensaje": "Ejemplar eliminado de la colección", "id": 1 }

📊 Estadísticas /api/estadisticas

GET /api/estadisticas/resumen Token

Totales del catálogo y de tu colección: juegos, plataformas, géneros, ejemplares, favoritos, valoración media e inversión total.

GET /api/estadisticas/por-plataforma Token

Juegos del catálogo y ejemplares tuyos, agrupados por plataforma (con fabricante).

GET /api/estadisticas/por-genero Público

Juegos del catálogo agrupados por género.

GET /api/estadisticas/por-estado Token

Tus ejemplares agrupados por estado (nuevo, bueno, digital…).

GET /api/estadisticas/top-valoraciones Token

Los 10 ejemplares de tu colección mejor valorados.

👥 Usuarios /api/usuarios

GET /api/usuarios Gestor

Lista las cuentas de la plataforma con búsqueda y paginación.

Parámetros de consulta
ParámetroTipoDescripción
qstringBusca por nombre, email o rol.
rolstringFiltra por rol exacto: usuario | gestor | admin.
paginaintPágina (defecto 1).
por_paginaintResultados por página (1–100, defecto 12).
GET /api/usuarios/{usuario_id} Gestor

Ver los datos de una cuenta concreta.

PATCH /api/usuarios/{usuario_id}/rol Admin

Cambia el rol de una cuenta. No puedes cambiar tu propio rol y siempre debe quedar al menos un administrador.

Cuerpo

Cuerpo JSON

{ "rol": "gestor" } // "usuario" | "gestor" | "admin"
PATCH /api/usuarios/{usuario_id}/password Admin

Restablece la contraseña de otra cuenta sin conocer la anterior (proceso de recuperación). Anula las sesiones abiertas de esa cuenta. Para la tuya propia usa POST /api/auth/cambiar-password.

Cuerpo

Cuerpo JSON

{ "password_nueva": "recuperada-123", // 6–72 caracteres "confirmar": "recuperada-123" // debe coincidir }
DELETE /api/usuarios/{usuario_id} Admin

Elimina una cuenta y, en cascada, su colección. No puedes eliminar la tuya propia.

Respuesta { "mensaje": "Cuenta de maic@ejemplo.com eliminada junto con 3 ejemplar(es) de su colección", "id": 2, "ejemplares_eliminados": 3 }
